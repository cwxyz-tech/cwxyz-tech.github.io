Heads up: the apps aren't signed with a paid certificate, so your computer will warn you the first time. That's normal for small free apps. The steps below show how to get past it.
How to Install

Windows

  1. Right-click the zip, choose Extract All, and open the Cole's Games folder.
  2. Double-click Cole's Games.exe.
  3. If you see "Windows protected your PC", click More info, then Run anyway.

Mac (takes about a minute, one time)

  1. Unzip it, then open Terminal.
  2. Type cd (with a space), drag the ColesGames folder into Terminal, and press Return.
  3. Run ./build.sh. If it asks for Apple's Command Line Tools, run xcode-select --install first.
  4. Drag Cole's Games.app into your Applications folder.

Linux

  1. Extract it and open a terminal in the Cole's Games folder.
  2. Run ./start.sh to play, or ./install.sh to add it to your app menu.
