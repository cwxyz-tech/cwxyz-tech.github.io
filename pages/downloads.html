Where's Windows? There's no Windows version, and that's on purpose. I don't agree with what Microsoft is doing with Windows 11 right now, and I'm only really comfortable backing systems built on Unix. Mac and Linux are what I've used my whole life, and I've barely ever used Windows.
Heads up: the apps aren't signed with a paid certificate. That's normal for small free apps. The steps below show how to set them up.
How to Install

Mac (takes about a minute, one time)

  1. Unzip it, then open Terminal.
  2. Type cd (with a space), drag the ColesGames folder into Terminal, and press Return.
  3. Run ./build.sh. If it asks for Apple's Command Line Tools, run xcode-select --install first.
  4. Drag Cole's Games.app into your Applications folder.

Linux

  1. Extract it and open a terminal in the Cole's Games folder.
  2. Run ./start.sh to play, or ./install.sh to add it to your app menu.
